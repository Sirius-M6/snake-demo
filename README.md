# 贪吃蛇

一个基于 JavaFX 开发的贪吃蛇小游戏,支持豆子积分策略、穿墙、障碍地图、三级难度与存档。

> **文档同步说明**:本 README 的「界面设计」「游戏规则」章节与《9.8需求文档.md》(v1.6,2026-09-08)保持一致;「分工与协作」的开发模块映射基于功能清单 FP-01~FP-17(即《PRD.md》6.1.2,与需求文档 3.11 内容一致)。规则细节、验收标准与待确认项以两份需求文档为准。

## 项目简介

本项目使用 Java 17 与 JavaFX 17 开发。玩家通过键盘方向键控制蛇的移动,吃到不同豆子获得不同积分并改变蛇身长度;**可以穿墙**;地图内设有**主题障碍**(管道、雪山等),撞到障碍或自身则游戏结束;**分数 < 0 也会失败**。游戏提供 低/中/高 三级难度,速度随得分阶梯式加快;支持暂停、**保存游戏(单存档)**与**按地图独立统计的最高分记录**。

**模块间协作约定**:

- 三模块共享 `model/`(数据模型)与 `config/`(参数),开发前由 PM 牵头晨会确认当日涉及的模型字段与接口,避免三端并行冲突。
- 依赖方向:`view`(A)只读引擎状态做渲染,B/C 不依赖 `view`;B 负责豆子/倒计时/存档数据,C 负责运动与碰撞判定;大毒豆场景由 B 完成扣分与计时后通知 C 切换方向映射(FP-08)。
- 一个功能点跨模块时,主模块先行实现,协作模块当日跟进联调,AC 由当日测试统一验收。

### 每日协作流程与分支约定

1. **晨会**:PM 按 6.1.2 排期从 P0/P1 池选定当日功能点,分派至 A/B/C 三模块(各模块约 1~2 个功能点,按当日验收重点平衡);
2. 开发各自实现并自测,提交分支 `feature/<MMdd>-<模块>-<FP>`,如 `feature/0908-C-FP04`;
3. 联调后交两名测试执行关联 AC 与异常用例,登记问题并修复回归;
4. PM code review 通过后合入 `dev`;`main` 仅保留可运行版本;
5. 当日轮值 PM 汇总日报(模板沿用 9.7 开发日报)。

- 右上角有**返回键**,点击回到主界面。

- 展示历史最高分,**记录按地图单独统计、不区分难度**(每张地图一条最高分)。

- 棋盘**右上角**:常驻**暂停按钮**(点击弹出暂停弹窗)。

## 游戏规则

### 开始一局

1. 主界面先通过「游戏难度」「地图」选定组合(也可不选,使用默认组合),点「开始新游戏」进入游戏界面。
2. 游戏界面初始为**待开始**状态,蛇静止于画面中央;按任意方向键(↑ ↓ ← →)开始移动。

### 移动与转向

| 按键 | 功能 |
| ---- | ---- |
| ↑(上方向键) | 蛇向上移动 |
| ↓(下方向键) | 蛇向下移动 |
| ←(左方向键) | 蛇向左移动 |
| →(右方向键) | 蛇向右移动 |

- **禁止掉头**:蛇不能直接反向移动。例如蛇正在向右时按 ←(左)无效,需先转 ↑ 或 ↓ 再转 ←。
- **快速连按**:两次方向键间隔 ≤ 0.15 秒视为同时按键,只按"最后有效按键"执行。
- **可以穿墙**:蛇头越过一侧边界后从对侧边界对应位置同向穿出;若穿出位置是障碍,同样算撞墙结束。

### 豆子一览

| 豆子 | 分值 | 蛇身变化 | 说明 |
| ---- | ---- | ---- | ---- |
| 小豆子 | +1 | +1 节 | 常见豆,随机出现在空白格 |
| 大豆子 | +6 | +1 节 | 高分豆,随机出现在空白格 |
| 毒豆子 | -6 | 不变 | 只扣分,不减蛇身 |
| 大毒豆子 | -10 | 不变* | 扣分并触发**方向键颠倒 2 秒**(期间 ↑↓←→ 方向全部取反) |
| 减负金豆 | +6 | 消除 2~3 节 | 救场豆,消除蛇身 2~3 节(*细节见需求文档) |

豆子刷新规则:场上**同时最多存在 3 颗豆子**,且**始终保持至少 1 颗小豆子**(小豆子被吃后立即补刷 1 颗小豆子)。**限时豆会自动消失**:毒豆子与大毒豆子在场 **3 秒**、大豆子与减负金豆在场 **5 秒**,未被吃掉即消失(暂停期间计时冻结);消失后补刷新:若场上还有其他非小豆子,延迟 **3 秒**补刷 1 颗(按生成比例抽取);若场上只剩小豆子,则空位留待小豆子被吃时一并补出。刷新位置不会落在蛇身或障碍上;场上可走空格 **< 10 个时不再刷新毒豆子与大毒豆子**,只刷正面豆;生成比例:小豆子 : 减负金豆 : 大豆子 = **3 : 1 : 1**,毒豆子 : 大毒豆子 = **3 : 1**;**大豆子与减负金豆不会同时在场**。

### 速度与难度

- 难度分 **低 / 中 / 高** 三档,决定开局移动速度(低慢、中中、高快)。
- **随分数阶梯提速**:一局内速度随本局得分阶梯式加快(达到分数阈值即升档),并设有**速度上限**(具体数值以需求文档为准)。

### 暂停、保存与继续

- 游戏中按**空格键**暂停/继续;或点击**右上角暂停按钮**弹出暂停弹窗(继续 / 保存游戏 / 终止游戏)。
- **保存游戏**:存档位只保留**最近一次未完结游戏**(单存档,**不分地图与难度**),再次保存会覆盖旧存档。
- **继续游戏**:主界面点「继续游戏」读取该存档继续游玩。

### 游戏结束

出现以下任一情况时本局结束:

1. **撞到自己**:蛇头碰到蛇身。
2. **撞到障碍**:蛇头碰到地图障碍(含穿墙穿出位置为障碍)。
3. **分数 < 0**:吃毒豆等扣分结算后总分为负。
4. 在暂停弹窗选择「**终止游戏**」。

游戏结束后显示**最终得分**与**当前地图的历史最高分**;按 **R 键**重开,按 **Esc 键**退出。

### 记录与最高分

- 最高分**按地图单独记录,不区分难度**;每张地图只有一条最高分记录,仅当本局得分更高时覆盖。
- 主界面「记录」按钮可查看各地图最高分。

### 操作快捷键汇总

| 按键 | 功能 |
| ---- | ---- |
| ↑ ↓ ← → | 控制方向 / 开始游戏 |
| 空格键 | 暂停 / 继续(含关闭暂停弹窗) |
| R | 结算画面重新开始 |
| Esc | 退出游戏 |
