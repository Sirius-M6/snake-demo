# 贪吃蛇

一个基于 JavaFX 开发的经典贪吃蛇小游戏。

## 项目简介

本项目使用 Java 17 与 JavaFX 17 开发，实现经典的贪吃蛇游戏。玩家通过键盘方向键控制蛇的移动，吃到食物后蛇身变长并得分，撞到墙壁或自身则游戏结束。

## 项目结构

```
src/main/java
├── config/   # 游戏配置
├── model/    # 数据模型（蛇、食物等）
├── util/     # 工具类
├── view/     # 界面视图
└── org/example/
    └── MainApp.java   # 程序入口
```

## 运行方式

### 方式一：直接运行主类

在 IDE 中运行 `org.example.MainApp` 的 `main` 方法。

### 方式二：Maven 运行

```bash
mvn javafx:run
```

## 游戏操作

- 方向键（↑ ↓ ← →）：控制蛇的移动方向
- 吃到食物：蛇身变长，得分增加
- 撞墙或撞到自己：游戏结束
