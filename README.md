# 贪吃蛇

一个基于 JavaFX 开发的经典贪吃蛇小游戏。

## 项目简介

本项目使用 Java 17 与 JavaFX 17 开发，实现经典的贪吃蛇游戏。玩家通过键盘方向键控制蛇的移动，吃到食物后蛇身变长并得分，撞到墙壁或自身则游戏结束。

在 IDE 中运行 `org.example.MainApp` 的 `main` 方法。

```bash

```

## 游戏操作

### 开始游戏

- 游戏启动后自动进入**待开始**状态，蛇静止在画面中央。
- 按任意方向键（↑ ↓ ← →）即可**开始游戏**，蛇开始朝该方向移动。

### 控制蛇的移动

| 按键 | 功能 |
| ---- | ---- |
| ↑（上方向键） | 蛇向上移动 |
| ↓（下方向键） | 蛇向下移动 |
| ←（左方向键） | 蛇向左移动 |
| →（右方向键） | 蛇向右移动 |

> **注意：** 蛇不能直接反向移动。例如蛇正在向右移动时，按 ←（左）无效，需先转向 ↑ 或 ↓ 再转向。这是为了避免蛇头直接撞上自己的身体。

### 游戏暂停与继续

- 按 **空格键（Space）** 可在游戏进行中**暂停**，再按一次**继续**。
- 暂停时蛇停止移动，方便玩家思考下一步方向。

### 得分规则

- 蛇吃到食物后，**蛇身长度 +1**，**得分 +10**。
- 食物被吃掉后，会在画面空白处**随机重新生成**一个。
- 得分越高，说明蛇越长，游戏难度越大。

### 游戏结束

出现以下任一情况时游戏结束：

1. **撞墙**：蛇头碰到游戏区域边界。
2. **撞到自己**：蛇头碰到自己的身体。

游戏结束后：

- 画面会显示**最终得分**。
- 按 **R 键** 可**重新开始**一局新游戏。
- 按 **Esc 键** 可**退出游戏**。

### 操作快捷键汇总

| 按键 | 功能 |
| ---- | ---- |
| ↑ ↓ ← → | 控制方向 / 开始游戏 |
| 空格键 | 暂停 / 继续 |
| R | 重新开始 |
| Esc | 退出游戏 |
